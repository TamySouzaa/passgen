📑 Caso de Uso: Gerar Senha Segura
Ator Principal: Usuário final (via CLI ou interface gráfica futura).

Objetivo: Criar uma senha aleatória e segura para uso em contas ou sistemas.

Pré-condições:

O sistema está instalado e acessível.

O usuário tem acesso ao terminal ou interface.

Pós-condições:

Uma senha válida é gerada e exibida.

Opcionalmente, a senha é copiada para o clipboard ou salva em arquivo.

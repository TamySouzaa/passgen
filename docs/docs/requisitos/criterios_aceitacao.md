✅ Critérios de Aceitação
História 1

A senha deve conter pelo menos uma letra maiúscula, uma minúscula, um número e um símbolo.

A senha deve ser gerada de forma aleatória a cada execução.

História 2

O usuário deve poder definir o comprimento da senha entre 12 e 64 caracteres.

Se o usuário não definir o comprimento, o padrão será 16 caracteres.

História 3

Após gerar a senha, o sistema deve copiá-la automaticamente para o clipboard.

O usuário deve receber uma mensagem confirmando que a senha foi copiada.

História 4

O sistema deve permitir salvar a senha em um arquivo .txt.

O arquivo deve ser criado com permissões restritas (somente leitura pelo usuário).
